# Future Task: Make Task Feedback Impossible to Miss

## User feedback
Users consistently ignore the investigation content panel on the right side of the screen. Important task information and completion feedback should not depend on that panel.

## Planned improvement
Add a contextual message pop-up after each task is completed at every level. The pop-up should appear close to the relevant task or in a clear central location in the game view, so players immediately understand what happened and what to do next.

The feedback should:

- Appear immediately after the related task action.
- Clearly describe the result of the action.
- Show the reward or item discovered when relevant.
- Give a short, useful next-step hint.
- Use smooth entrance and exit animations.
- Keep dismissed messages available in a message log opened by a “?” icon in the top-right corner, so players can review which messages belong to each level after clicking “OK” or pressing Enter.
- Organize the message log by level and clearly identify the relevant task, result, reward or discovered item, and next-step hint.
- Avoid interrupting movement or hiding important gameplay for too long.
- Work consistently across the ground floor, first floor, and second floor.

## First room follow-up
Apply the same contextual task-message system to the first room later. Do not change the first-room task feedback as part of the current work; this should be handled in a separate follow-up.

## Scope
This is a future usability and polish task. It is documented now and can be implemented later without changing the current gameplay flow.
