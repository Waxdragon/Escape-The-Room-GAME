# The Last Room

A browser-based 3D escape-room game built with React, Vite, Three.js, and React Three Fiber.

Explore Northmere House, investigate clues, solve the study, and survive the haunted chamber long enough to find the final key.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Controls

- **WASD** — move
- **Mouse** — look around
- **Enter** — interact
- **P** — pause/resume
- **F**, **Space**, or **click** — fire when armed
- **Right click** or **Shift** — aim
- **R** — reload

## Build for production

```bash
npm run build
npm run preview
```
